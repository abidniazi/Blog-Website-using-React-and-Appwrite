# ToolForge — Free Online Tools for Students & Developers

🌐 **Live:** [freetoolforge.org](https://freetoolforge.org)

56+ free tools built with Next.js 14, TypeScript, Tailwind CSS, and Gemini AI.

## Features
- 24 Calculators (EMI, Tax, IELTS, University Merit, Zakat)
- 8 Text Tools (AI Summarizer, Grammar Checker, Paraphraser, Essay Writer)
- 9 Developer Tools (Online Compiler, QR Generator, JSON Formatter)
- 15 Document & Image Tools (PDF suite, Image Compressor)
- 16 In-depth Guides (Freelancing, Tax, Investment, University Admissions)

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Gemini AI (5-key rotation system)
- Vercel (deployment)
